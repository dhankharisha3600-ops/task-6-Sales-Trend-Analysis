# Task 6 - Sales Trend Analysis Using Aggregations

## Objective
Analyze monthly revenue and order volume using SQL aggregate functions.

## Tools Used
- DB Browser for SQLite
- SQLite

## Dataset
Created an online_sales table containing order_id, order_date, amount, and product_id.

## Steps Performed
1. Created the online_sales table.
2. Inserted sample sales data.
3. Calculated monthly revenue using SUM().
4. Calculated order volume using COUNT(DISTINCT order_id).
5. Grouped data by month and year.
6. Sorted results using ORDER BY.
7. Retrieved the top 3 months by sales.

## Outcome
Learned how to use aggregate functions, GROUP BY, ORDER BY, SUM, COUNT, and sales trend analysis in SQL.
